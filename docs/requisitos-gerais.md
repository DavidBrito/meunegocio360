# Projeto MeuNegocio360 - Documento de Requisitos (Frontend)

## Visão Geral: Arquitetura do Sistema
| Módulo | Objetivo | Funcionalidades |
|---|---|---|
| Núcleo | Base empresarial | Gestão de usuários, clientes, fornecedores, produtos, serviços, vendas, contas a pagar e receber, fluxo de caixa e dashboard. |
| Serviços | Operação de serviços | Gestão de técnicos, equipamentos, solicitações, ordens de serviço (OS), execução, evidências, aceite e faturamento das OS. |
| Suprimentos | Estoque e Compras | Movimentações, estoque mínimo, inventário, compras, reposição, curva ABC, giro de estoque e alertas. |
