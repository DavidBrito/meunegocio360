# Projeto MeuNegocio360 - Documento de Requisitos

## Frontend
- Stack utilizada: React JS com Vite
- Paleta de cores: deve ser definidad como estilos globais.
    - Laranja: #EC4E26 (botões primários, barra de navegação, texto de botões onHover e secundários)
    - Creme: #FCF5F0 (fundo das páginas e cartões)
    - Cinza: #3E3C38 (linha das tabelas, bordas dos cartões e texto secundário)
    - Preto: #1f1612 (texto principal)
    - Laranja amrronzado claro: #CDBBAE (rodapé)
- Fonte:
    - Barlow Condensed (pesos 500, 600 e 700): para títulos.
    - Barlow (pesos 400, 500 e 600): para textos, tabelas e rodapés.
